## 三网优化到底优化了什么，怎么识破缩水版

国内三家运营商的普通国际出口都挤在 163、4837 这些骨干网上，晚高峰丢包和延迟一起上来。三网优化就是让三家各走一条更贵的专用链路。

**电信 CN2 GIA**：中国电信下一代承载网的最高档，回程全程走 CN2 节点。163 骨干网像国道，CN2 GIA 像收费高速，车少路宽，晚高峰不堵。

**联通 AS9929**：也叫 CUG-9929，地位相当于联通的 CN2 GIA。普通联通用户回程走 4837，9929 单独走高品质链路，丢包和延迟都更稳。

**移动 CMIN2**：新版中移精品网，比老的 CMI（AS58453）质量好。老 CMI 晚高峰经常跑不满带宽，CMIN2 是它的升级版，两者不是一回事。

三条齐全才叫三网优化，缺一条就是缩水版。市面上常见的缩水方式是只优化电信和联通，移动走普通 CMI，白天看不出问题，晚上八点移动用户打开网页转圈。

还有一档更便宜的选择是软银回程：从日本 BBTEC 直进上海联通口，联通用户体验很好，电信和移动基本没优化。这种机器适合只需要联通线路的人，价格比三网精品低不少，买之前要知道自己买的是“偏科生”。

日本 VPS 的回程大体就三档：普通 BGP 直连最便宜，晚高峰丢包严重；软银单线对联通友好；三网 CN2 GIA / 9929 / CMIN2 最贵也最均衡。Akile 的日本系列落在第一档和第二档之间，走的是 IIJ、CMI 这类方向的调优，后面细说。

## 流量超了会怎样：停机、限速、不限量

DMIT 的 Pro 系列超量后暂停服务，站点直接打不开，恢复要等下个计费周期或手动加购。T1 系列超量后不停机，降速继续用，WEE 限 50Mbps，其他型号限 100–500Mbps。LisaHost 有真正不限流量的型号，Lite 版 ¥598/月、Pro 版 ¥1598/月，代价是带宽只有 200–500Mbps。
